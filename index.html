Featured Project

Techdemy LMS

View live

What it is

  • A Learning Management System for Techdemy. The pilot cohort took 100 students.
  • Three user types catered for: Students, Admins, and Facilitators.
  • Students can view their cohort, curriculum, and deadlines.
  • Admins can view all students, cohorts, and curricula.
  • Facilitators can view all students, cohorts, curricula, manage assignments, grades, and messages. They can also create new cohorts and curricula.

How it's built

  • TypeScript across a Next.js web app and a NestJS API.
  • TanStack Query for server data. UI state stays separate from that.
  • PostgreSQL for records, Redis for cache and queues, and a separate worker for background jobs.
  • Course files stay in private storage and open only through short-lived links.
